## Description
Add practice mode support to the engine. Extend `GameEngine` constructor to accept `mode` and `startLevel` options. In practice mode: initialize a countdown timer, decrement it in `tick()`, emit `TIME_WARNING` at 10s remaining, trigger game over with `reason: 'timeout'` when timer expires, and keep the level fixed. Update `ScoreManager` to support `fixedLevel` option.

## Acceptance Criteria
- [ ] `GameEngine` constructor accepts `{ mode?: GameMode; startLevel?: number }` options
- [ ] In practice mode, `remainingMs` initializes to `PRACTICE_DURATION_MS` (120000)
- [ ] In marathon mode, `remainingMs` is `null`
- [ ] `tick()` decrements `remainingMs` by `deltaMs` in practice mode
- [ ] `TIME_WARNING` event emitted exactly once when `remainingMs` crosses below 10000ms
- [ ] Game over triggers with `reason: 'timeout'` when `remainingMs <= 0`
- [ ] Game over triggers with `reason: 'topout'` on spawn collision (both modes)
- [ ] `ScoreManager` accepts `{ startLevel?: number; fixedLevel?: boolean }` options
- [ ] When `fixedLevel` is true, `checkLevelUp()` always returns `null`
- [ ] Gravity uses the fixed `startLevel` in practice mode (no level advancement)
- [ ] `getSnapshot()` includes `gameMode` and `remainingMs` fields
