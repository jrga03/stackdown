## Description
Implement SRS rotation with wall kick offset tables for JLSTZ, I, and O piece categories. For a rotation from state A to state B, compute kick offsets as `offsetTable[A][i] - offsetTable[B][i]` and test up to 5 positions. Record the kick index on success for T-spin detection.
