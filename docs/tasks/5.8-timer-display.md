## Description
Create a `TimerDisplay` HUD component that shows the remaining time in practice mode as a MM:SS countdown. The component applies a warning style (red color, CSS pulse animation) when the timer drops to 10 seconds or below. Only rendered when `gameMode === 'practice'`.

## Acceptance Criteria
- [ ] Displays remaining time in MM:SS format (zero-padded)
- [ ] Label reads "TIME"
- [ ] Rounds up to nearest second using `Math.ceil(remainingMs / 1000)`
- [ ] Clamps display to 00:00 minimum (never shows negative)
- [ ] Adds `timer-warning` CSS class when `remainingMs <= 10000`
- [ ] Warning state applies red color and pulse animation
- [ ] Only rendered in `GameScreen` when `gameMode === 'practice'`
- [ ] Positioned in the right side panel below LinesDisplay
