## Description
Implement gravity timing that drops pieces at level-appropriate speeds. Uses an accumulator pattern: each tick adds `deltaMs`, and when the accumulator exceeds the level's interval, the piece drops one cell. At high levels, multiple drops can occur in a single tick.

## Acceptance Criteria
- [ ] `getIntervalForLevel(level)` returns correct ms/cell for levels 1-15
- [ ] `tick(deltaMs, level)` accumulates time and returns cells to drop
- [ ] At level 1 (1000ms), tick(1000) returns 1
- [ ] At level 1, tick(500) returns 0, then tick(500) returns 1
- [ ] At high levels (e.g., level 15 = 7ms), multiple drops in a single tick
- [ ] `reset()` clears the accumulator
