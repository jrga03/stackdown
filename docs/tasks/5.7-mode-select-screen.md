## Description
Create the mode selection screen that appears between MainMenu and GameScreen. Players choose Marathon or Practice mode via toggle buttons. In Practice mode, a level picker (1-15 slider) appears. The screen passes a `GameConfig` to the game via the `onStart` callback. Update `MainMenu` to navigate to `'mode-select'` instead of `'game'`.
