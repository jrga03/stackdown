## Description
Implement Delayed Auto-Shift and Auto-Repeat Rate for movement actions. On key press: fires immediately, then charges DAS (167ms default). After DAS charges, fires every ARR interval (33ms default). If ARR=0, fires BOARD_WIDTH actions instantly. Left/right priority: most recently pressed direction wins.
