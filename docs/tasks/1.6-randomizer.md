## Description
Implement the 7-bag randomizer with optional seeded PRNG. Each bag contains exactly one of each piece type, shuffled with Fisher-Yates. The queue is pre-filled with 2 bags (14 pieces). Supports deterministic sequences via seed for testing and replays.

## Acceptance Criteria
- [ ] Each bag contains exactly one of each piece type (7 unique)
- [ ] `next()` returns pieces in shuffled order
- [ ] `next()` auto-generates a new bag when the current bag is exhausted
- [ ] `peek(n)` returns the next N pieces without consuming them
- [ ] After `peek(5)`, `next()` returns the same piece that was first in peek
- [ ] Queue is pre-filled with at least 14 pieces (2 bags)
- [ ] Seeded randomizer produces the same sequence given the same seed
- [ ] Different seeds produce different sequences
- [ ] Unseeded randomizer produces varied sequences
- [ ] All tests pass
