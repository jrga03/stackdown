## Description
Implement the main `GameEngine` class that orchestrates all engine subsystems. Handles tick-based gravity, player actions (move, rotate, drop, hold), piece spawning, line clearing, score updates, and game over detection. Exposes `getSnapshot()` for the renderer and UI.

## Acceptance Criteria
- [ ] Constructor creates a new game with empty board, spawns first piece, fills next queue
- [ ] `tick(deltaMs)` advances gravity and lock delay; no-op when paused or game over
- [ ] `applyAction(MOVE_LEFT/RIGHT)` moves piece if valid
- [ ] `applyAction(SOFT_DROP)` moves piece down 1 cell, awards 1 drop point
- [ ] `applyAction(HARD_DROP)` drops to lowest position, awards 2 pts per cell, locks immediately
- [ ] `applyAction(ROTATE_CW/CCW/180)` rotates with wall kicks
- [ ] `applyAction(HOLD)` swaps active piece with hold; rejected if already used this piece
- [ ] `applyAction(PAUSE)` toggles pause state
- [ ] `getSnapshot()` returns a complete `GameSnapshot`
- [ ] Game over triggers when a new piece cannot spawn
- [ ] After piece locks, full rows are cleared and score updated
- [ ] Events emitted: LINE_CLEAR, COMBO, BACK_TO_BACK, LEVEL_UP as applicable
- [ ] Lock delay activates on surface, resets on move/rotate
- [ ] Ghost piece position calculated correctly
- [ ] All tests pass
