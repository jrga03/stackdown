## Description
Implement T-Spin detection using the 3-corner rule. Check the 4 diagonal corners around the T piece center. If 3+ corners are occupied and the last action was a rotation, classify as proper T-Spin or T-Spin Mini based on front corner occupancy. Kick index 4 always yields a proper T-Spin.

## Acceptance Criteria
- [ ] Returns "none" for non-T pieces
- [ ] Returns "none" if last action was not a rotation
- [ ] Returns "none" if fewer than 3 corners are occupied
- [ ] Returns "proper" if 3+ corners and both front corners filled
- [ ] Returns "mini" if 3+ corners and only one front corner filled
- [ ] Returns "proper" if kick index is 4 (regardless of front corners)
- [ ] Correctly identifies front corners for each rotation state
- [ ] Out-of-bounds positions (walls, floor) count as occupied
- [ ] Above-board positions (y < 0) count as NOT occupied
- [ ] Tests cover: proper T-Spin, Mini, no T-Spin, kick-index-4
