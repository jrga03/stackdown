## Description
Map keyboard codes to game actions. Uses `KeyboardEvent.code` (physical key position) for layout-independent mapping. Default bindings: arrows for movement, Space for hard drop, Up/Z/A for rotation, Shift for hold, Escape for pause. Supports rebinding via `updateBindings()`.
