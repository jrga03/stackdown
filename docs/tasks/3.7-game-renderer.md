## Description
Implement the main render orchestrator that coordinates all sub-renderers. Draws each frame in order: grid → locked blocks → ghost → active piece → effects. Handles canvas context creation with `{ alpha: false }`, resize/cell-size recalculation, and active piece Y interpolation for smooth gravity.
