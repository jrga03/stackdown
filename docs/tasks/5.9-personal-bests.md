## Description
Create a `usePersonalBests` hook that persists the highest score per mode (marathon, practice) in `localStorage`. The hook exposes a `checkAndUpdate(mode, score)` method that returns `true` if the score is a new personal best. This is used by the game over flow to show a "NEW PERSONAL BEST!" indicator.

## Acceptance Criteria
- [ ] `PERSONAL_BESTS_KEY` is `'stackdown-personal-bests'`
- [ ] `PersonalBests` interface has `marathon: number` and `practice: number` fields
- [ ] Default values are `{ marathon: 0, practice: 0 }`
- [ ] Hook reads from `localStorage` on mount (gracefully handles missing/corrupt data)
- [ ] `checkAndUpdate(mode, score)` returns `true` and persists when score exceeds current best
- [ ] `checkAndUpdate(mode, score)` returns `false` when score does not exceed current best
- [ ] `bests` state object is exposed for reading current personal bests
- [ ] Data persists across page reloads
