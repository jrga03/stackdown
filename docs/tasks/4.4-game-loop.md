## Description
Implement a fixed-timestep game loop using `requestAnimationFrame`. Uses an accumulator pattern: each frame adds its deltaMs to an accumulator, then processes as many fixed-size ticks (16.667ms) as needed. Frame time is clamped to 250ms to prevent spiral of death when the tab is backgrounded. Passes interpolation factor to the render callback.
